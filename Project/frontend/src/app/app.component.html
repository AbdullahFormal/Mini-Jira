Help & Demo

This mini task manager supports:

  • Register and Login (JWT authentication)
  • Create / Delete Projects (Manager only)
  • Create / Update / Delete Tasks inside a project
  • Role-based UI (Manager / Developer)

Demo users (seeded):

  • Manager: manager@example.com / password
  • Developer: dev@example.com / password

How to use the demo:

  1. Login with one of the demo users above.
  2. Managers can create projects; developers can open projects and add tasks.
  3. Use the Next button on a task to advance its status (TODO → IN_PROGRESS → DONE).
