📖 MiniJira Quick Start Guide

1. Authentication

Register with your own name, email, and password, choosing a role. Or use our seeded demo users:

  • Manager: manager1@example.com / password
  • Developer 1: dev1@example.com / password
  • Developer 2: dev2@example.com / password

2. Manager Role

  • Create and structure projects with descriptions.
  • Delete projects when they are complete.
  • Oversee work distribution and progress.

3. Developer Role

  • Open projects to see active tasks.
  • Create new tasks for the project.
  • Advance task status: TODO → IN_PROGRESS → DONE using the Next button.
